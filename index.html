Hubungkan Database dulu

Aplikasi ini menyimpan jurnal ke Google Spreadsheet lewat Google Apps Script. Untuk mencoba, isi URL deployment di file assets/js/site-config.js.

  1. Buat spreadsheet baru di https://sheets.new lalu beri nama, misal "Jurnal 7 Kebiasaan SD".
  2. Menu Ekstensi → Apps Script, hapus isi Code.gs, lalu tempel seluruh isi file apps-script/Code.gs dari repository ini.
  3. Deploy → New deployment → Web app: Execute as Me, Who has access Anyone.
  4. Salin URL yang berakhiran /exec, lalu tempel ke assets/js/site-config.js pada baris scriptUrl.
  5. Login sebagai guru dengan guru / guru123, lalu segera ganti password.
